## Pixel_art_organiser
Learning project
I built this project while developing my Python skills.

I used AI assistance during development to help me understand Python concepts, debug problems, and explore different implementation approaches.

I reviewed and tested the code myself and am continuing to improve my understanding of the project.

This program can: 
- Add new assets
- List assets
- Find assets by name
- Edit assets
- Remove assets
- Save assets to a JSON file
- Load assets from a JSON file

## Technologies
- Python
- JSON
- pytest
- Git / GitHub
